# Drive Transfer: সেটআপ গাইড (Reja's Studio)

এই অ্যাপে এডিটরের ড্রাইভ লিঙ্ক পেস্ট করে, নিজের ড্রাইভের একটা ফোল্ডার বেছে **Proceed** চাপলে ভিডিওটা ফোনের নেট (ওয়াইফাই বা মোবাইল ডাটা) দিয়ে **ডাউনলোড আর আপলোড একসাথে** হয়।
ফাইল টুকরো টুকরো করে নামে আর সাথে সাথে উঠে যায়, তাই ফোনের স্টোরেজে কিছু জমা হয় না। ১০ GB-র ভিডিও হলেও সমস্যা নেই।

পুরোটা ফ্রি। শুধু একবার এই সেটআপটা করতে হবে (২০–৩০ মিনিট)।

---

## ধাপ ১: অ্যাপটা অনলাইনে রাখুন (GitHub Pages, ফ্রি)

1. **github.com**-এ একটা ফ্রি অ্যাকাউন্ট খুলুন।
2. **New repository** চাপুন। নাম দিন `drive-transfer`, তারপর **Public** রেখে Create করুন।
3. **Add file → Upload files** চাপুন। এই ৬টা ফাইল আপলোড করে **Commit** করুন:
   `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`
4. **Settings → Pages**-এ যান। Source হিসেবে **Deploy from a branch** দিন, Branch: `main`, ফোল্ডার: `/ (root)`। তারপর **Save** করুন।
5. ১–২ মিনিট পর অ্যাপের ঠিকানা পাবেন: `https://আপনার-ইউজারনেম.github.io/drive-transfer/`

## ধাপ ২: Google Client ID বানান (ফ্রি)

1. **console.cloud.google.com**-এ যান। উপরে প্রজেক্ট মেনু থেকে **New Project** বানান।
2. **APIs & Services → Library**-তে গিয়ে **Google Drive API** খুঁজে **Enable** করুন।
3. **OAuth consent screen** (বা "Google Auth Platform") খুলুন:
   - User type: **External**
   - App name: `Drive Transfer`, আর নিজের ইমেইল দিন
   - **Audience / Test users**-এ নিজের Gmail যোগ করুন (যেটার ড্রাইভে ভিডিও রাখবেন)
4. **Credentials → Create credentials → OAuth client ID** চাপুন:
   - Application type: **Web application**
   - **Authorized JavaScript origins**-এ লিখুন: `https://আপনার-ইউজারনেম.github.io` (শেষে `/` বা `/drive-transfer` দেবেন না)
5. **Create** চাপলে যে **Client ID** পাবেন (`….apps.googleusercontent.com`), সেটা কপি করে রাখুন।

> অ্যাপটা "Testing" মোডে থাকবে, আর শুধু আপনি (Test user) এটা ব্যবহার করতে পারবেন। সাইন-ইনের সময় "Google hasn't verified this app" দেখাতে পারে। তখন **Continue** চাপুন। এটা আপনার নিজের অ্যাপ, তাই সমস্যা নেই।

## ধাপ ৩: ফোনে অ্যাপ হিসেবে ইনস্টল করুন

1. ফোনের **Chrome**-এ অ্যাপের ঠিকানাটা খুলুন।
2. ⋮ মেনু থেকে **Add to Home screen** বা **Install app** চাপুন। এখন হোম স্ক্রিনে সাধারণ অ্যাপের মতো আইকন থাকবে।
3. অ্যাপ খুলে Client ID পেস্ট করে **সেভ** করুন, তারপর **সাইন ইন** করুন।

iPhone-এ Safari থেকে **Share → Add to Home Screen** দিয়ে একইভাবে ইনস্টল করা যায়।

## ব্যবহার

1. **এডিটরের লিঙ্ক** পেস্ট করুন। ফাইলের নাম আর সাইজ সাথে সাথে দেখাবে। ফোল্ডারের লিঙ্ক দিলে ভেতরের সব ফাইল যাবে, সাব-ফোল্ডারসহ।
   - Android-এ Drive অ্যাপ থেকে **Share → Drive Transfer** চাপলেও লিঙ্কটা নিজে থেকে বসে যাবে।
2. **ফোল্ডার বাছুন**: নিজের ড্রাইভের ফোল্ডার ঘুরে দেখে বাছতে পারবেন, খুঁজতে পারবেন, নতুন ফোল্ডারও বানাতে পারবেন। আগে বাছা ফোল্ডারগুলো 🕘 চিপ হিসেবে থাকবে।
3. **Proceed** চাপলে কী হবে তা দেখিয়ে আপনার **অনুমতি** চাইবে। মোবাইল ডাটায় থাকলে কতটা ডাটা খরচ হবে সেটাও জানাবে।
4. চলার সময় স্পিড, কতটা হয়েছে আর কত সময় বাকি তা দেখাবে। শেষ হলে **লিঙ্ক কপি** করে ক্লায়েন্টকে পাঠাতে পারবেন।

### অপশন
- **ফোনের নেট দিয়ে ডাউনলোড + আপলোড** (ডিফল্ট): আপনি যেভাবে চেয়েছেন।
- **সরাসরি ড্রাইভ থেকে ড্রাইভে কপি**: Google-এর সার্ভারেই কপি হয়। ফোনের ডাটা লাগে না, কয়েক সেকেন্ডে শেষ হয়। ডাটা বাঁচাতে চাইলে এটা ব্যবহার করুন।
- **লিঙ্ক শেয়ার-যোগ্য করুন**: শেষ হলে "Anyone with the link – Viewer" করে দেয়, যাতে ক্লায়েন্ট খুলতে পারে।

### জরুরি কথা
- এডিটরের লিঙ্কটা **"Anyone with the link"** হতে হবে, অথবা আপনার ইমেইলের সাথে শেয়ার করা থাকতে হবে।
- ট্রান্সফার চলার সময় **অ্যাপটা খোলা রাখুন**। স্ক্রিন নিজে থেকে বন্ধ হবে না। অন্য অ্যাপে গেলে ফোন এটাকে থামিয়ে দিতে পারে।
- নেট কেটে গেলে অ্যাপ অপেক্ষা করে, আর নেট ফিরলে যেখানে থেমেছিল সেখান থেকে আবার শুরু করে।
- এক ঘণ্টার বেশি চললে Google সেশন রিনিউ করতে একবার "রিনিউ" চাপতে বলবে।
- স্পিড কম হলে ⚙️ সেটিংসে চাঙ্ক সাইজ বদলাতে পারেন: দুর্বল নেটে 4 MB, ভালো ওয়াইফাইতে 16–32 MB।
